# Wincars Design Guideline

Design guideline page created in Figma: https://www.figma.com/design/cVG8QGhFsJzdVNQE3Kf7nr/WINCARS-Poland

Page: **Design Guideline** (остання сторінка у файлі)

## Секції гайдлайну

1. **Brand Colors** — Primary Yellow #FFCD11, Yellow Light #FFDE64, Yellow Dark #E6B800, сіра шкала, білий
2. **Typography** — H1 (56px Bold) → Label (11px Bold), шрифт Inter
3. **Spacing System** — 8px базова сітка: 4, 8, 12, 16, 24, 32, 48, 64, 80, 120px
4. **Border Radius** — None, 4px, 8px, 12px, Full (100px для кнопок)
5. **Buttons & CTAs** — Primary, Secondary, Arrow CTA, Hover, Disabled
6. **Form Elements** — Default input, Focused input, List/menu row
7. **Navigation & Header** — Лого, nav links, active underline, CTA button
8. **Car Card Component** — Default state, Hover state (yellow border + glow)
9. **FAQ / Accordion** — Closed, Open з відповіддю
10. **Footer** — Dark background, links, copyright
11. **Arrows & Icons** — →←↑↓ + − ×
12. **Shadows & Elevation** — sm, md, lg, yellow glow
13. **Do's & Don'ts** — правила використання бренду
